# 📝 Prueba – Programación Orientada a Objetos

Este repositorio contiene el desarrollo de la prueba correspondiente a la asignatura de **Programación Orientada a Objetos**.

## 📋 Descripción

El proyecto implementa los requerimientos solicitados en la prueba utilizando las tecnologías indicadas, aplicando buenas prácticas de programación y organización del código.

## 🛠️ Tecnologías utilizadas

- Java 17
- Maven
- MySQL
- JavaFX / Spring Boot 

## 📂 Estructura del proyecto

```text
src/
├── main/
│   ├── java/
│   └── resources/
└── test/
```

## ▶️ Requisitos

- JDK 17 o superior
- Maven
- MySQL
- IDE recomendado: IntelliJ IDEA o Eclipse

## 🚀 Ejecución

1. Clonar el repositorio.

```bash
git clone <URL_DEL_REPOSITORIO>
```

2. Abrir el proyecto en el IDE.

3. Configurar la conexión a la base de datos (si aplica).

4. Ejecutar la clase principal del proyecto.
